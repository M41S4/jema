## Sobre o projeto

O **JEMA TMS** é um sistema desenvolvido para auxiliar transportadoras e operadores logísticos na identificação do veículo mais adequado para o transporte de determinadas cargas.

A plataforma utiliza informações dos produtos vinculados às notas fiscais, como peso e volume, para realizar cálculos e comparar as características da carga com as capacidades dos caminhões cadastrados.

Com base nesses dados, o sistema apresenta opções de veículos compatíveis com a carga informada, facilitando a escolha do transporte adequado e reduzindo o risco de incompatibilidade entre a mercadoria e o veículo.

## Objetivos

- Calcular o peso e o volume total de uma carga.
- Consultar as capacidades dos caminhões cadastrados.
- Comparar as características da carga com as capacidades dos veículos.
- Identificar e apresentar o caminhão mais adequado para o transporte.
- Auxiliar na tomada de decisão durante a seleção do veículo.

## Indicação de caminhões

Uma das principais funcionalidades do JEMA TMS é identificar qual caminhão é mais adequado para transportar uma determinada carga.

O sistema considera:

- Peso total da carga (kg).
- Volume total da carga (m³).
- Capacidade máxima de peso do caminhão.
- Capacidade máxima de volume do caminhão.

A partir dessas informações, o sistema compara os requisitos da carga com as capacidades dos veículos cadastrados e apresenta os caminhões compatíveis.

O objetivo é facilitar a escolha do veículo, garantindo que ele tenha capacidade suficiente para transportar a carga informada.

## Objetivo final

O JEMA TMS tem como propósito simplificar a seleção de veículos para operações logísticas, utilizando dados de peso e volumetria para identificar o caminhão mais adequado para cada carga.

A proposta é aplicar tecnologia e automação de cálculos para tornar a escolha do veículo mais rápida, organizada e precisa.
